## [1.3.0]

### Added

- Colors for Copilot chat and inline chat, the Source Control graph, test result icons, keybinding labels, banners, and Markdown quote/code blocks.
- Whole-line backgrounds in side-by-side diffs.
- Light bulb, scrollbar error/warning/change marks, and status bar error/warning colors.
- Legacy indent guide colors for VS Code versions before 1.66.
- Shell: command names and the `$` in variables are colored.
- Go: import paths use the string color.

### Changed

- Remaining gray UI colors (line numbers, indent guides, borders, scrollbars, sidebar and menu text) are tinted teal to match the theme.
- Diff highlights use the theme's green and coral.
- Line numbers and search placeholder text are easier to read.

### Fixed

- C# labels were colored by a Markdown rule; they now use the type color.
- Removed 11 duplicate or dead syntax rules (no visible change).

## [1.2.0]

### Added

- Colors for bracket pairs, inlay hints, sticky scroll, inline suggestions (ghost text) and the command center.
- Marketplace banner color and a full README.

### Fixed

- Diff files: added lines are now green and removed lines red (they were reversed).
- Keyboard focus outline is now visible.
- Buttons, inputs, dropdowns and checkboxes now stand out from the background.
- Drag-and-drop feedback in lists and the sidebar.
- Active panel tab is now brighter than inactive tabs.
- Extension size: the 14 MB animated icon was replaced with a 256×256 PNG.

### Changed

- Strings and comments are brighter for better readability.
- Default editor text is soft cream instead of bright yellow.
- Terminal red, blue, magenta and black colors are readable on the teal background.
- Theme file renamed to `themes/flat-color-theme.json`.
- Selections, menus, peek view, links and split-editor borders use teal instead of leftover default blues.
